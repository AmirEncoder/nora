# NOORA — وب‌سایت مجله تصویری

یک وب‌سایت فارسی راست‌چین با هویت بصری متفاوت: سبز زیتونی، کرم کاغذی، نارنجی سفالی، عکس‌های بزرگ و چیدمان مجله‌ای. مناسب انتشار روی هاست Linux/cPanel با PHP و MySQL؛ نیازی به Node.js، React یا ساخت (build) ندارد.

## محتویات
- `index.php` صفحه اصلی واکنش‌گرا
- `assets/css/style.css` طراحی و چیدمان
- `assets/js/main.js` منوی موبایل و انیمیشن ورود عناصر
- `subscribe.php` ثبت ایمیل در دیتابیس
- `database.sql` جدول مورد نیاز
- `includes/config.php` تنظیمات اتصال MySQL

## انتشار روی cPanel
1. وارد cPanel شو و از **MySQL® Database Wizard** یک دیتابیس و کاربر بساز.
2. کاربر را به دیتابیس اضافه کن و دسترسی **ALL PRIVILEGES** بده. نام کامل دیتابیس و کاربر معمولاً پیشوند نام اکانت cPanel دارد.
3. از **phpMyAdmin** دیتابیس را انتخاب کن، وارد زبانه **Import** شو و فایل `database.sql` را وارد کن.
4. فایل ZIP را در `public_html` بارگذاری و Extract کن. مطمئن شو `index.php` مستقیماً داخل `public_html` قرار گرفته، نه داخل یک پوشه اضافی.
5. فایل `includes/config.php` را ویرایش کن و `DB_NAME`، `DB_USER` و `DB_PASS` را با اطلاعات واقعی عوض کن. `DB_HOST` در بیشتر هاست‌ها `localhost` است؛ اگر شرکت هاست مقدار دیگری داده، همان را بگذار.
6. دامنه را باز کن. فرم «نامه نورا» بعد از تنظیم دیتابیس ایمیل‌ها را ذخیره می‌کند.

## تصاویر و فونت
عکس‌ها از Unsplash و فونت‌ها از Google Fonts بارگذاری می‌شوند؛ برای نمایش این منابع، مرورگر بازدیدکننده باید به این سرویس‌ها دسترسی داشته باشد. اگر هاست یا مخاطبان دسترسی ندارند، عکس‌های مجاز را دانلود و در پوشه `assets/images` قرار بده و آدرس‌های `background-image` در CSS را به فایل‌های محلی تغییر بده.

## نکات مهم
- این بسته یک صفحه اصلی کامل و فرم خبرنامه با ذخیره‌سازی MySQL دارد؛ بخش مقالات در این نسخه نمونه‌های نمایشی هستند و سیستم مدیریت محتوا/پنل ادمین ندارد.
- ایمیل‌های ثبت‌شده در جدول `subscribers` ذخیره می‌شوند. برای دیدنشان از phpMyAdmin استفاده کن و اطلاعات دیتابیس را عمومی نکن.
- برای سایت زنده، SSL دامنه را در cPanel فعال کن.
- ایمیل `hello@example.com` در فوتر نمونه است؛ آن را با ایمیل خودت عوض کن.
