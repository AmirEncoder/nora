# نصب پنل مدیریت NOORA در cPanel

1. قبل از هر کاری از `public_html` و دیتابیس نسخه پشتیبان بگیرید.
2. فایل ZIP را در `public_html` آپلود و Extract کنید؛ باید پوشه `admin` مستقیماً داخل `public_html` قرار بگیرد.
3. مطمئن شوید `public_html/includes/config.php` اطلاعات دیتابیس درست را دارد. رمز دیتابیس را برای کسی نفرستید.
4. باز کنید: `https://YOUR-DOMAIN/admin/install.php` و حساب مدیر بسازید. رمز را حداقل ۱۲ کاراکتر و قوی انتخاب کنید.
5. بلافاصله پس از ساخت مدیر، فایل `public_html/admin/install.php` را حذف کنید.
6. ورود: `https://YOUR-DOMAIN/admin/login.php`

امکانات: داشبورد، افزودن/ویرایش/حذف مقاله، وضعیت پیش‌نویس/منتشرشده، مشاهده خبرنامه، تغییر رمز مدیر.

**مهم:** این افزونه برای جلوگیری از خراب شدن سایت فعلی، `index.php` را بازنویسی نمی‌کند. مقاله‌ها در جدول `noora_articles` ذخیره می‌شوند؛ نمایش خودکار آن‌ها روی صفحه اصلی نیازمند اتصال کارت‌های فعلی `index.php` به این جدول است.

اگر خطای دیتابیس دیدید، در cPanel → MySQL Databases بررسی کنید کاربر دیتابیس به دیتابیس متصل و دارای ALL PRIVILEGES باشد. مقادیر DB_HOST، DB_NAME، DB_USER و DB_PASS در `includes/config.php` باید صحیح باشند.
